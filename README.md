# Виджет «Открыть ворота» (4×2) для Android — v1.1

Лёгкое Android-приложение на Kotlin, которое добавляет на рабочий стол виджет 4×2 с фоновым изображением и единственной текстовой кнопкой **«Открыть ворота»** (без иконки телефонной трубки, без СМС и без колокольчика уведомлений). При нажатии на кнопку сразу совершается телефонный вызов (`Intent.ACTION_CALL`), не открывая приложение «Телефон» с карточкой контакта.

## Что нового в версии 1.1
- **Тёмные контрастные поля ввода**: оба поля («Номер телефона ворот / шлагбаума» и «Подпись на виджете») выполнены на тёмно-графитовом фоне (`#1E2228`) со светлым текстом и чёткой рамкой, поэтому отлично видны даже при включённой системной тёмной теме смартфона.
- **Выбор темы кнопки виджета**: переключатель **«Тёмная кнопка»** (`#22252A` с белым текстом) и **«Светлая кнопка»** (`#FFFFFF` с тёмным текстом) с мгновенным обновлением предпросмотра и самого виджета на рабочем столе.
